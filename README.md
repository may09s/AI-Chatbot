\# AI Chatbot



A simple AI chatbot built with Python and OpenRouter.



\## Features



\- AI-powered chat

\- Uses OpenRouter API

\- Built with Python

\- Easy to customize



\## Installation



```bash

pip install requests

```



\## Setup



Set your OpenRouter API key:



```bash

setx OPENROUTER\_API\_KEY "your\_api\_key\_here"

```



\## Run



```bash

python chatbot.py

```



\## Example



```text

You: Hello

AI: Hi! How can I help you today?

```
